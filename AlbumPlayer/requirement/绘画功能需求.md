# Agent Prompt: 为 Qt6 图片浏览器增加绘图/批注功能

## 1. 项目背景与现状
我目前正在开发一个基于 Qt6 的图片播放器/浏览器。目前的项目状态是：
- **技术栈**：C++ (或 Python, 按你的实际项目选择) + Qt6
- **UI 结构**：左侧是文件目录树，中间是主图片显示区域，底部是状态栏。
- **现有功能**：基本的图像加载、上一张/下一张、文件树浏览。

## 2. 本次新增的需求（功能清单）
请为我开发一套**图片绘图/批注功能**。具体要实现以下 7 种工具：
1. **调色板**：能自由切换/选取颜色。
2. **矩形框选**：按住鼠标拖拽绘制矩形框（空心或实心）。
3. **椭圆框选**：按住鼠标拖拽绘制椭圆/圆形。
4. **随手画（画笔/涂鸦）**：按住鼠标自由手绘线条。
5. **文字**：点击图片某处，弹出文字输入框确认后，在相应位置写入文字。
6. **马赛克**：一种特殊的涂抹模式，能把画笔经过的像素像素化（打马赛克）。
7. **橡皮**：擦除已经画在上面的内容，露出原始图片。

## 3. 交互与 UI 设计要求

### 3.1 功能进入位置 (Entry Point)
- 在主图片上**点击鼠标右键时**，展开一个上下文菜单（QMenu）。
- 在右键菜单中追加一个新条目：**“进入绘图模式”**（快捷键可自由设置）。
- 选中该条目后，应用自动进入绘图状态，并显示绘图工具栏。

### 3.2 绘画 UI 位置与风格 (UI Layout & Style)
- **位置**：UI 工具栏排布在**图片显示区域的右侧**。
- **样式**：实现为一个**浮空面板 (Floating Panel)**。
    - 面板宽度建议在 280px ~ 350px 之间。
    - 使用暗色主题（Dark Mode），完全呼应主界面的风格。
    - 面板需要带**阴影效果 (Drop Shadow)**，增加层次感。
- **面板组件排布**：面板内从上到下按行或区域排列：
    - [颜色选择器/调色板]
    - [工具按钮区：矩形、椭圆、画笔、文字、马赛克、橡皮]
    - [其他操作：清空全部绘图、退出绘图模式(或切换回正常浏览)]

## 4. 需要我帮你补充的专业开发细节 (Agent 技术建议)
在实现上述基本功能时，请务必在代码层面融入以下**关键架构和修复点**，以保证程序稳定好用：

### 4.1 数据层面：图层与分离 (Undo/Redo 准备)
- **绝对不能直接修改源图片 (Source Image)**！应该像 Photoshop 一样，在源图片上方叠加一个**透明的虚拟图层 (Overlay Layer)**。
- 推荐使用 `QGraphicsView` + `QGraphicsScene` + `QGraphicsPixmapItem` 架构：
    - `BaseLayer`: 底层的原始图片。
    - `DrawLayer`: 顶层用于绘图。
- 或者使用 `QPainter` 在原始 `QImage` 的副本上绘制（但不是最佳实践，不易撤回）。

### 4.2 用户体验：撤销/重做 (Undo/Redo)
- 默认带上最基本的 3 步“撤销”和“重做”功能。这一步非常重要，建议使用 Qt 提供的 `QUndoStack` 框架。

### 4.3 性能优化
- **马赛克工具**：需要笔刷涂抹的效果，计算量很大。不要在 `mouseMoveEvent` 中每帧都处理整个图像。
- 建议做法（获取涂抹区域像素块 -> 计算均值 -> 赋值），使用 OpenCV 会有更成熟的马赛克算法，如果不方便引入外部库，则优化 Qt `QImage` 像素操作。

### 4.4 视图与逻辑分离
- 当用户点击“退出绘图模式”或按 `ESC` 时，隐藏浮空面板，移除可能的额外图层，恢复纯粹的浏览模式。

### 4.5 图标支持
- 所有绘图工具栏上的按钮，请使用 Qt 的 `QAction` + 自定义 `QToolButton`，并找到一套简洁的 SVG/PNG 图标（或使用 Qt 内置的 Style 图标 `QStyle::SP_...`）。

## 💡 “加分项”：
1. **笔触粗细**：除了调色板外，增加一个滑动条（QSlider）或下拉框，让用户可以控制画笔/橡皮的粗细大小。
2. **图片缩放后的坐标校正**：如果浏览图片时有放大/缩小功能（Zoom），绘制层的坐标必须和图片的显示坐标**严格对齐**，否则鼠标画偏了。
3. **不透明度 (透明画笔)**：调色板中增加一个滑动条控制画笔的不透明度（Alpha值）。
4. **保存与导出**：在绘图面板底部增加一个“保存到新图片/覆盖原图”的按钮，用于保留批注结果。
